# Money Tracker

เว็บบันทึกรายรับรายจ่ายแบบ Minimal สำหรับ GitHub Pages

## Features
- Dashboard รายเดือน
- รายรับ / รายจ่าย / เงินออม / เงินลงทุน
- หมวดค่าใช้จ่าย
- เป้าหมายการเงิน
- ประวัติรายการและค้นหา
- Export / Import JSON
- ไม่ต้องมี server หรือ database

## Deploy
1. สร้าง GitHub repository
2. อัปโหลด `index.html`, `style.css`, `app.js`, `README.md`
3. ไปที่ Settings → Pages
4. Source: Deploy from branch
5. เลือก `main` และ `/ (root)`
6. Save
